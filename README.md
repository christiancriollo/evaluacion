## Sobre el proyecto

Esto no es una página web más. **TechZone** es una tienda de tecnología pensada para quien quiere lo mejor sin complicarse la vida: productos modernos, útiles y accesibles, presentados con un diseño limpio, elegante y directo al punto.

Una interfaz oscura con detalles en azul eléctrico, navegación clara y un catálogo que entra por los ojos. Cero ruido, cero relleno, pura tecnología.

## Diseño que se adapta a todo

Se ve impecable en computadora, tablet y celular. La estructura se reorganiza sola según el tamaño de la pantalla, sin perder estilo en ningún dispositivo.

---

## Tecnologías

- **HTML5** para la estructura semántica.
- **CSS3** para el diseño: Flexbox, Grid y media queries.
- Sin frameworks. Sin dependencias. Sin vueltas.

El CSS está incluido dentro de cada archivo HTML, así que cada página es totalmente independiente.
